# Console RPG (C#)

A minimalist turn-based text RPG running in the terminal.

## Features

- Custom hero name and health tracking
- Multiple locations and enemy types (Zombie, Vampire)
- Turn-based combat choices: Attack, Heal, or Run away (random chance)
- Enemy counterattacks

## Built With

- C# (.NET)
- Object-Oriented Programming (OOP)
- Interactive console game loop
